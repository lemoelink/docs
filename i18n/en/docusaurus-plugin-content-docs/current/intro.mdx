# Quick Start Guide

:::warning Development Phase
This project is currently in active development phase. However, its core functionality (routing, model loading and backends) is fully operational and stable for use.
:::

**LEMoE (Light Easy Mix Of Experts)** is an intelligent routing middleware for AI. It receives your prompts, analyzes them and routes them to the most suitable specialized model — completely transparent to your applications.

:::info What does LEMoE do?
LEMoE acts as a proxy compatible with the OpenAI and Ollama API. You don't need to change your code: simply change the base URL and LEMoE handles the rest.
:::

:::tip Online Configurator
Do you prefer to create your configuration visually? Use the [LEMoE Online Configurator](http://config.lemoe.link/) to easily generate your `experts.json` file.
:::

---

## 3-step Installation

### 1. Clone and prepare

```bash
git clone https://github.com/lemoelink/lemoe.git
cd lemoe
chmod +x setup.sh
./setup.sh
```

The `setup.sh` script creates the virtual environment, installs dependencies and generates the default configuration files.

### 2. Configure your first expert

Edit `config/experts.json` and add your first expert:

```json
{
  "max_experts": 15,
  "experts": [
    {
      "id": 1,
      "label": "programmer",
      "description": "Expert in writing, reviewing and debugging source code.",
      "keywords": [
        "code", "program", "python", "javascript", "function",
        "script", "error", "bug", "html", "css", "class", "object",
        "module", "api", "refactor"
      ],
      "type": "ollama",
      "url": "http://127.0.0.1:11434",
      "model_name": "qwen2.5-coder:7b"
    }
  ]
}
```

### 3. Start

```bash
./start.sh
```

The server starts at `http://0.0.0.0:11435`. Ready!

## Connect your first client

### Open WebUI

**Option A: Ollama-type Connection (Recommended)**
1. Go to **Settings → Connections → Ollama API**
2. Base URL: `http://your-ip:11435`
3. Save and reload — you will see all your experts as available models.

**Option B: OpenAI-type Connection**
1. Go to **Settings → Connections → OpenAI API**
2. Base URL: `http://your-ip:11435/v1`
3. API Key: any value (LEMoE ignores it)
4. Save and reload.

### cURL / any OpenAI client

```bash
curl http://localhost:11435/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "Write a Python function to sort a list"}],
    "stream": false
  }'
```

LEMoE automatically detects that it is a code question and routes it to the `programmer` expert.
